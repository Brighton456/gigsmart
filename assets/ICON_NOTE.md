# Icon Pipeline
- Base logo source lives at `assets/gigs-logo.png`.
- Run `npm run optimize:logo` after updating the base logo to regenerate favicon/app icons.
- Final icons:
  - `Icon.png` / `icon-192.png` / `icon-512.png`
  - `favicon-16.png` / `favicon-32.png` / `favicon.png`
  - `gigs-logo-web.png` for in-app usage.
